# Отчет по SEO-оптимизации проекта PC Club

## Проделанная работа:
1. **Базовые метатеги**: В файле `index.html` добавлены `charset`, `viewport`, уникальные `title` и `description`. Указан язык страницы `lang="ru"`.
2. **Структура заголовков**: Выстроена правильная иерархия. Используется один `<h1>`, подразделы разбиты на `<h2>` и `<h3>`. Текст не имитирует заголовки через `<div>`.
3. **Robots.txt**: Создан файл в папке `wwwroot`, закрывающий от сканирования `/api/`, `/scalar/` и страницу `/login.html`.
4. **Sitemap.xml**: Создана карта сайта с абсолютными адресами (пока используется заглушка `https://example.com`).
5. **Защита приватных страниц**: На странице `login.html` установлен метатег `<meta name="robots" content="noindex, nofollow">`.
6. **Защита API**: В `Program.cs` добавлен middleware, который проставляет заголовок `X-Robots-Tag: noindex, nofollow` для всех ответов по пути `/api/`.
